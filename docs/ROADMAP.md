# 维护路线图

以 [0.4.1](https://github.com/mik1e80/moonbit-cad-sketch/releases/tag/v0.4.1) 为稳定基线。当前维护集中在小型二维参数化草图、尺寸编辑、诊断和应用集成。圆弧、37 种用户约束与几何生命周期已有发布证据，见[功能矩阵](FEATURE_MATRIX.md)及[完整回归](COMPLETENESS_VALIDATION.md)。

| 优先级 | 事项 | 验收证据 |
| --- | --- | --- |
| P0 | 维护已发布接口的独立应用案例 | [圆角板](REGISTRY_PLATE.md)从 Mooncakes 固定安装，核对尺寸联动、测量、诊断和失败恢复 |
| P0 | 保护编辑状态、圆弧边界和数值结果 | 修改相关代码时检查解析期望、引用保护、快照隔离、预算及失败写回边界 |
| P0 | 处理实际反馈和安全报告 | 普通问题保留最小复现、版本、后端和结果。安全报告走[私密渠道](../SECURITY.md) |
| P1 | 扩充代表性测量与兼容性证据 | 记录模型、编译器、系统、后端、预算和实际命令。跨版本比较使用相同条件 |
| P1 | 评估表达式参数和批量编辑 | 先明确实际应用需求、依赖关系、循环和错误语义，再决定公开 API |
| 后续评估 | 修剪、自动圆角及更多曲线 | 以实际使用需求决定，三维实体、大型装配、文件交换及 CAD 界面保持独立应用职责 |

日常以受影响的检查和四后端轻量 CI 为准。发布候选按[发布流程](PUBLISHING.md)单独记录完整回归、包内容和仓库外安装。0.4.2 留作有必要的修复版本。0.5.0 的 API 方向根据集成反馈评估。已发布的包和标签保留原样。

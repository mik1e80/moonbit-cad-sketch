# 0.4.0 验收标准

1. checked 几何与关系创建/编辑失败不写入；删除受引用保护，编号与快照不串用。
2. Arc 有真实有限方向、内置半径一致性、弧相关关系、SVG 路径；失败结果不应用。
3. 每个返回方程有稳定几何/关系来源；停止原因与局部秩可解释。
4. 冗余和冲突分析保留预算、试验结果和候选边界；不输出严格不可满足或最小冲突证明。
5. 原有 400 配置套件保留，新增 480 配置独立版本计数；方向、退化、所有权、删除、导数及检查器故障注入有测试。
6. 四后端源码完整回归、原有生成模型和独立解包消费通过后才发布；发布后从注册表安装并测试公开 API。
7. README、接口摘要、许可证、模型来源与发布证据一致；未执行测量标历史或待验证，不伪造统计。

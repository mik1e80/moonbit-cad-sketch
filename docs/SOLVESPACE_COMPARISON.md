# 与 SolveSpace 的范围对照

本项目参考公开功能分类组织需求，不是 SolveSpace 源码移植，也不声称兼容其文件、求解分支、约束编号或全部行为。

| 分类 | 本库 0.4.0 | 边界 |
| --- | --- | --- |
| 草图点、线、圆 | 提供 | 小型二维草图 |
| 有限圆弧 | 提供 | 显式圆心、起终点与方向；无自动裁剪 |
| 尺寸与几何约束 | 37 种用户关系 | 名称相近不代表完整等价，见 CONSTRAINT_SPEC |
| 构造几何 | 提供 | 角色和 SVG 显示；仍参与方程 |
| 参考尺寸 | 只读测量 | 无界面标注布局、单位换算或表达式系统 |
| 矩形工具 | 四点四边辅助 | 不自动附加水平、垂直或尺寸关系 |
| 冗余与失败排查 | 数值局部候选 | 无严格冗余证明或最小不可满足集 |
| 二维机构 | 四杆连续编辑案例 | 不保证构型保持、完整运动学或碰撞检测 |
| 界面、历史、文件 | 宿主应用负责 | 不读取 SolveSpace 文件 |
| 三维、曲面、实体、装配 | 不在范围 | 无旋转/拉伸实体或布尔运算 |
| 导入导出 | SVG 草图显示 | 无 DXF/STEP/STL 互转 |

功能核对来源：[官方约束介绍](https://solvespace.com/constraints.pl)、[官方参考手册](https://solvespace.com/ref.pl)、[技术说明](https://solvespace.com/tech.pl)。此处为自行编写的功能对照，未复制其实现、测试模型、截图或文档段落。通用数学方法不构成源码依赖；本库 Apache-2.0，不宣称 SolveSpace 的源码受本库许可证覆盖。

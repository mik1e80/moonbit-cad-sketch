# 二维草图完整化范围

稳定基线：0.3.0；目标：0.4.0。本文是实现合同，实际交付状态以 FEATURE_MATRIX 和对应测试记录为准，计划不视为已实现。

范围包括 Point / Line / Circle / Arc、尺寸与几何等式、受预算约束的求解及局部诊断、编辑生命周期、参考测量、构造几何、SVG。核心运行时仍为纯 MoonBit。GUI、三维、Bezier / Spline / NURBS、DXF / STEP、全局搜索、严格 MUS 证明、稀疏增量求解不在本轮范围。

所有公开操作须校验草图归属；checked 写入失败必须原子；删除不得复活旧 ID；被几何或现存约束引用的对象默认不可删除。禁用关系仍视为引用，避免重新启用悬挂关系。不提供隐式级联删除。

现有 256 标量变量、512 线、512 现存用户约束继续有界，新增圆弧单独限制容量和内置方程。圆弧是求解对象，不只是 SVG 装饰；其定义方程不能被禁用。几何、用户关系和诊断方程需要可追溯来源。

成功以返回世界坐标重新计算的残差为准。局部秩不是全局刚性证明；删除对照成功仅表示该试验恢复了满足解，失败不证明数学无解。诊断不得改变当前草图，必须报告次数和预算耗尽。

每项新关系需有公式、单位、残差维度、域/退化、归属、解析与导数测试；新增模型使用自建解析数据或注明种子的生成规则，不引入未授权第三方语料。规范见 MODEL_DATA_POLICY。

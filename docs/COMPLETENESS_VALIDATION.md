这些是有限拓扑下的配置，不是 480 个外部工业模型。MoonBit 测试内用独立几何公式核对，不把同进程测试称为外部认证或独立求解器对照。新增导数测试避开分段切换处；另有端点、失败恢复、生命周期和错误输入行为测试。旧 SciPy 对照与 Benchmark 时间快照仍为历史测量，不表示新增圆弧经过 SciPy 对照。

复现：moon test --target <wasm|wasm-gc|js|native> --deny-warn。新增配置位于 arc_test.mbt 和 diagnostics_analysis_test.mbt；其余新增边界、编辑与导数测试不计入 480。测试条目数与循环配置数分别报告。运行 scripts/completeness.mbtx 保存源码检查和生成案例日志；完整发布记录最终见本文件后续实测段落。

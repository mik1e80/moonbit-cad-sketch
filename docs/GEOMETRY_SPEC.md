# 几何、所有权与生命周期约定

坐标和长度由调用方统一单位；角度为弧度。所有句柄属于创建它的 Sketch，不能序列化为跨进程或跨草图标识。

Point 占两个标量变量；Line 引用两个不同位置的现存 Point；Circle 引用现存圆心 Point，半径另占一个变量。Arc 引用 center/start/end 三个 Point 与方向，不额外创建半径变量，并始终提供一个等半径方程。其完整定义见 [ARC_DESIGN](ARC_DESIGN.md)。

现存上限为 256 标量变量、512 条线、128 条圆弧、512 条用户约束（含禁用项）。圆数量同时受标量变量上限约束。圆弧方程不占用户约束槽。构造角色不改变容量或求解含义。

各类型 index 是单调创建编号，不是压缩数组位置；删除释放现存容量但不复用编号。编号达到 Int32 分配上限时 checked 接口返回 IdentifierExhausted。删除仍被几何或任何现存约束引用的对象，包括禁用约束，返回 GeometryInUse。先显式删除约束，再删除圆弧/线/圆，再删除不再被引用的点；不隐式级联。旧 Solution 独立保留几何及编号快照。

checked 创建和编辑验证定义与资源限制，失败不写入、不消耗编号；不保证新关系已数值满足。编辑点可能使依赖线或圆弧退化，后续 solve / SVG 会再次验证完整几何。try_set_arc 也检查既有圆弧相切关系的共享端点定义。旧便利接口适用于可信输入，不能作为输入安全隔离。

ConstructionGeometry 仍参与求解；to_svg(show_construction=false) 只隐藏该实体，端点角色独立设置，自动视野仍包含所有几何。measure 是只读计算，不驱动求解。try_add_rectangle 原子创建四点四边，不隐式创建约束，不是自动圆角工具。

Sketch 为可变对象，宿主负责并发隔离、持久化、撤销和资源调度。本库没有文件解析、网络服务、线程安全保证或工程制造认证。

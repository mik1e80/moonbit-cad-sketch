# 诊断合同与术语

普通 solve 不执行子集搜索。SolveReport 单独保留状态、停止原因、世界坐标逐方程来源与误差、用户关系残差、圆弧内置几何残差、局部秩和自由度。

冗余分析在同一数值构型上，比较完整雅可比与排除一条用户关系后的归一化局部秩。仅在满足容差的基线报告 LocallyRedundantCandidate；逐条排除不意味着可同时删除所有候选。保留圆弧内置方程，禁用关系不作为候选。必须报告秩评估次数、容差与未完成预算状态。

冲突分析以当前几何快照为相同初值，通过有界的关系排除、子集再求解，报告实际观察到的未满足子集与恢复建议。不得把局部求解失败用作严格不可满足判定，也不得称结果为已证明的最小冲突集。任何候选须带约束 ID、尝试结果、QR 总次数及预算状态；预算耗尽要明确区分未尝试和试验失败。

停止原因区分达标、无下降、步长过小、线性求解失败、迭代上限、QR 总预算和最终世界容差失败。不把数值停滞重命名为 Inconsistent。保留既有 SolveStatus 分类，新增字段属于可见接口变更，需迁移记录。

所有诊断在拷贝的数据上工作；不得临时改变调用者可见的 enabled、约束数组、几何或编号计数器。用户原草图、既有 Solution 和旧报告仍为独立快照。

# 维护与应用验证

## 0.4.1 基线与本轮实测

稳定包、四后端完整回归及独立安装见 [0.4.1 发布证据](COMPLETENESS_VALIDATION.md)。本轮发布检查已在专项验证之后单独完成，见[维护后发布验收](PUBLISHING.md#041-维护后发布验收--2026-11-20)。本轮 2026-11-20 的结果单独记录：

- [独立圆角安装板](REGISTRY_PLATE.md)实际运行于 Windows x64 的仓库外项目，从 Mooncakes 解析固定版本 0.4.1。验证尺寸联动、参考测量、SVG、冲突时保存几何及删除冲突后恢复，并记录代表性求解、导出及诊断耗时。该案例由维护者自建。当前没有登记经核实的第三方生产集成或用户反馈。
- 使用固定编译器 0.10.17+d971670cd 与匹配 core，Windows 上的 wasm、wasm-gc、JavaScript 和 native 各通过两项专项测试，覆盖 32 次同草图连续编辑及四个独立投影场景。连续编辑跨越半圆，检查非法写入不改变状态、禁用约束仍保护引用、删除后不复用编号，以及旧快照和报告隔离。语料见[来源清单](validation/maintenance-arc-sequence-v1.json)，命令见下文。

```sh
moon test maintenance_sequence_test.mbt --target js --deny-warn
```

将 `js` 换成 `wasm`、`wasm-gc` 或 `native` 可复现对应后端。两项测试已纳入四后端轻量 CI。此次验证未重跑完整 400 / 480 配置与 1000 随机初值套件，原版测试数字仍对应 [0.4.1 完整回归](COMPLETENESS_VALIDATION.md)。独立案例的计时与历史 Benchmark 和 SciPy 记录分开。

后续专项补验新增同一混合草图上的 12 次固定种子尺寸编辑，覆盖圆弧、线段相切及等半径圆的联动。每次编辑加入冲突并核对不写回、一次子集预算及恢复。另加入同一可解草图的两档秩阈值对照，核对局部候选随阈值变化且分析不改动草图。此前专项测试文件在 Windows 四后端各通过 4 项。本轮逐项复核加入零弧与整圆邻域、重复距离诊断，更新后各通过 6 项。新增的四个有向圆弧邻域构型由固定角偏移和三角函数生成，另有一个重复距离诊断构型。它们与测试源码按 Apache-2.0 分发，未作为已发布版的旧语料重复计数。新增语料见[清单](validation/maintenance-mixed-edit-v1.json)。[维护基准](BENCHMARK.md#041-维护基准)已实测线段、圆弧、冗余、删除及大 SVG。逐项交付和按需复核范围见[维护检查](MAINTENANCE_REVIEW.md#本轮计划逐项复核)。

## 提交可复现反馈

普通问题走 [GitHub Issues](https://github.com/mik1e80/moonbit-cad-sketch/issues/new/choose)，选择缺陷或集成请求模板。提供包版本、操作系统、`moon version --all`、目标后端、最小可公开代码、执行命令、期望与实际结果。数值问题注明参数、初值、容差和预算。反馈、复现和修复分别记录。安全问题走 [SECURITY 私密渠道](../SECURITY.md)。提交前移除私有图纸、凭据和个人信息。

## 维护与发布

[路线图](ROADMAP.md)列出后续工作和验收证据。日常验证变更涉及的行为。公开 API 变化时同步可执行示例、接口摘要、迁移和变更记录。引入外部依赖或模型时按[模型来源政策](MODEL_DATA_POLICY.md)和[贡献规则](../CONTRIBUTING.md)核对用途、许可、署名和再分发要求。

发布候选按[发布流程](PUBLISHING.md)记录源码提交、完整回归、安装包和仓库外注册表消费结果。保留各版本的原始记录与归档，待证据确认后再更新支持范围。
